# تثبيت نبتة على Windows

## التشغيل المحلي المباشر

الإصدار الحالي يعمل محلياً داخل تطبيق نبتة ولا يعرض صفحة ربط أو اكتشاف خادم. بعد التثبيت افتح الاختصار العادي؛ يبدأ مخزن البيانات المضمّن تلقائياً وتظهر شاشة الدخول مباشرة.

بيانات الدخول الأولية:

- اسم المستخدم: `admin`
- كلمة المرور: `admin`

لا يحتاج البرنامج إلى صلاحية مسؤول أثناء التشغيل، ولا ينشئ خدمة Windows أو قاعدة بيانات على الشبكة أو قواعد جدار ناري. تحفظ بيانات كل مستخدم ونسخه الاحتياطية داخل بيانات تطبيق نبتة المحلية، بعيدًا عن مجلد التثبيت. لا يحتاج صاحب المتجر إلى تثبيت PostgreSQL أو Node.js أو تنفيذ أوامر.

## التحديث وإعادة التثبيت

شغّل المثبت الجديد فوق النسخة الحالية. لا تحذف بيانات تطبيق نبتة المحلية من حساب Windows؛ فهي تحتوي على قاعدة البيانات والنسخ الاحتياطية. التحديث لا يحذف بيانات المبيعات أو المخزون.

## ملاحظات

ملف التثبيت غير موقّع رقمياً، لذلك قد يعرض Windows تحذير SmartScreen. اختر «مزيد من المعلومات» ثم «التشغيل» إذا كنت تثق في مصدر الملف. الطابعات والماسحات تعمل عبر أجهزة Windows المعتادة، بينما تكامل الدفع البنكي والضرائب يحتاج إعداداً منفصلاً.
