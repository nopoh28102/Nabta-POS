# سجل التراخيص والإصدارات

يستخدم الخادم `@electric-sql/pglite` 0.5.8 في الوضع الافتراضي. الحزمة مرخصة بمزيج Apache-2.0 وترخيص PostgreSQL، وتضم امتداد `pgcrypto` المطلوب لإنشاء المعرفات. راجع إشعار الحزمة المرفق قبل التوزيع التجاري.

الإصدار الأول يستخدم حزمًا مفتوحة المصدر بتراخيص متوافقة مع MIT/Apache-2.0: Electron وReact وVite وFastify وZod و`pg` وTypeScript وVitest وPlaywright وPostgreSQL. راجع `pnpm-lock.yaml` قبل التوزيع وأرفق إشعارات الحزم عند إنشاء مثبت مؤسسي. لا توجد خدمة سحابية أو اشتراك إلزامي أو أسرار داخل renderer.

تم اختيار الإصدارات المثبتة في `package.json` بعد مراجعة الوثائق الرسمية وقت التنفيذ. يجب إعادة المراجعة قبل تحديث الإنتاج، خصوصًا دورة دعم Electron وPostgreSQL وتوافق Windows.

## دعم قارئ COM

تستخدم نسخة سطح المكتب `serialport` و`@serialport/parser-readline` إصدار 13.0.0 بترخيص MIT، لعرض منافذ COM وفتح قارئ الباركود التسلسلي داخل عملية Electron الرئيسية فقط. تحتوي الحزمة مكوّناً أصلياً لـ Windows؛ ولذلك يجب اختبار تشغيل المثبّت على Windows الفعلي بعد كل تحديث للإصدار.
