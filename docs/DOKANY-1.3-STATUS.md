# نبتة دكاني 1.3.0 — الديون والتقارير وتجهيز الواجهة

**الحالة:** منفذ في مصدر التطبيق ومتحقق منه ببناء APK Debug محليًا.

## تحديث 1.3.1

- شاشة استلام المورد تستخدم بطاقات مدمجة: تختار كرتونة أو فرط أو كيس أو كيلو، فتظهر الحقول اللازمة لذلك الاختيار فقط.
- إذا كان الكيس أو الكرتونة غير معرّفين للصنف السابق، يمكن إدخال سعتهما من البطاقة نفسها وحفظهما في نبتة مع توليد الباركود تلقائيًا.
- أزرار منفصلة لمسح باركود الكرتونة وباركود الكيس، وتفاصيل متقدمة قابلة للطي لكل بند.
- تعطيل اقتراحات المتصفح/الملء التلقائي في حقول التشغيل؛ قائمة المورد فقط تظل قابلة للبحث المقصود.

- الديون: بحث بالاسم أو الهاتف، فلترة المدينين، عميل جديد مع مديونية افتتاحية، وسداد جزئي موثّق من رصيد العميل.
- التقارير: استدعاء تقرير نبتة الشامل وفق الفترة، عرض المبيعات والربح والمصروفات وأفضل الأصناف، وتصدير SpreadsheetML بامتداد `.xls` من منتقي ملفات Android.
- البيع: ترتيب النتائج المتاحة قبل غير المتاحة ومنع إضافة الصنف غير المتاح إلى السلة من نتيجة البحث.
- الشكل: هوية خضراء موحدة، رموز Emoji للنقل والوظائف، أحجام لمس مناسبة، دعم الشاشات الصغيرة والمتوسطة، ومنع قائمة تحديد النص غير المقصودة في WebView.
- الأمان: التصدير يمر عبر نافذة حفظ Android ولا يمنح واجهة HTML وصولًا إلى الملفات، ومسار التقرير في جسر Android وWorker يظل ضمن قائمة مسارات ثابتة.

## التحقق المنفذ

```powershell
node --check apps/nabta-dokany/app/src/main/assets/receive-v12.js
node --check apps/nabta-dokany/app/src/main/assets/ui-v13.js
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-17.0.21.21-hotspot'
$env:ANDROID_HOME = 'C:\Users\ahmed\AppData\Local\Android\Sdk'
.\apps\nabta-inventory-scanner\gradlew.bat -p .\apps\nabta-dokany :app:assembleDebug --no-daemon --console=plain
```

التحقق البرمجي والبناء نجحا. يلزم نشر مصدر Worker المحدّث قبل أن يصل مسار `/v1/reports/comprehensive` إلى الهاتف عبر Cloudflare؛ لم يُنشر تلقائيًا في هذا التحديث.
