# تشغيل خادم نبتة على Windows

## الوضع الافتراضي: قاعدة مضمّنة بلا تثبيت

يستخدم الإصدار الحالي PGlite، وهي قاعدة PostgreSQL مضمّنة داخل عملية الخادم. لا يحتاج صاحب المتجر إلى تثبيت PostgreSQL أو تشغيل خدمة قاعدة بيانات منفصلة. تحفظ البيانات في `DATABASE_DIR` على جهاز الخادم الرئيسي فقط؛ أجهزة الكاشير لا تفتح هذا المجلد، بل تتصل بـ API عبر الشبكة المحلية.

هذا التصميم يدعم نقطتي بيع وأكثر ما دامت تستخدمان خادم نبتة نفسه. لا تشغّل نسختين من الخادم على مجلد البيانات نفسه، ولا تضع المجلد على مشاركة شبكة.

## الإعداد

1. ثبّت Node.js 24 LTS وpnpm على جهاز الخادم، ثم نفّذ `pnpm install`.
2. انسخ `.env.example` إلى `.env` خارج مجلد التطبيق. اترك `DATABASE_MODE=embedded` وحدد مساراً دائماً مثل `C:\ProgramData\Nabta\data\pglite`.
3. أنشئ `SETUP_TOKEN` عشوائياً بطول 20 محرفاً أو أكثر، وحدد `BACKUP_DIR` خارج مجلد التطبيق وعلى قرص احتياطي إن أمكن.
4. نفّذ `pnpm db:migrate` ثم `pnpm --filter @nabta/server build` ثم `pnpm --filter @nabta/server start`.
5. افتح التطبيق على الخادم، أدخل رمز الإعداد، وأنشئ حساب المالك وكلمة مرور قوية. لا توجد بيانات دخول افتراضية.
6. شغّل تطبيق الكاشير؛ سيبحث تلقائياً عن خادم نبتة على شبكة LAN ويستخدم عنوانه وبصمة TLS المعلنة. عند نجاح الاكتشاف اختر نقطة البيع في شاشة الدخول إن كان الجهاز جديداً. تفاصيل الخادم اليدوية موجودة في «الإعدادات» فقط.

في الإنتاج على LAN استخدم شهادة TLS موثوقة محلياً (`TLS_CERT_PATH` و`TLS_KEY_PATH`) وافتح منفذ API الداخلي فقط في جدار Windows. لا تكشف مجلد البيانات أو منفذ PostgreSQL (لأنه غير موجود في الوضع الافتراضي) للكاشير.

## الاكتشاف التلقائي على الشبكة

يستمع الخادم على UDP `47620` لرسالة اكتشاف قصيرة، ثم يعلن عنوان API فقط؛ لا تُرسل كلمات مرور أو بيانات قاعدة البيانات. يجب السماح بمنفذ UDP `47620` داخل شبكة المتجر، بالإضافة إلى منفذ API `7443`. في الإنتاج لا يقبل التطبيق اتصال LAN غير مشفّر: يلزم HTTPS وبصمة شهادة مطابقة. إذا حجب جدار Windows UDP، يمكن استخدام «الإعدادات ← إعدادات الاتصال» لإدخال العنوان والبصمة يدوياً.

## بديل PostgreSQL الخارجي

للمتاجر الأكبر يمكن اختيار `DATABASE_MODE=postgres` ووضع `DATABASE_URL` و`PG_DUMP_PATH`. هذا خيار اختياري، وليس شرطاً لتشغيل نبتة أو نقطتي البيع.

## الانقطاع والنسخ

عند انقطاع الشبكة تبقى مسودة السلة على الجهاز، لكن لا تصدر فاتورة نهائية. يعيد التطبيق الاستعلام عن مفتاح العملية بعد عودة الخادم لتجنب التكرار.

ينشئ المجدول نسخة يومية في `BACKUP_DIR`. في PGlite تكون النسخة أرشيف بيانات مضمّنة ويجب استعادتها بإصدار PGlite نفسه؛ اختبر الاستعادة على مجلد معزول قبل استبدال مجلد الإنتاج. في وضع PostgreSQL الخارجي تكون النسخة بصيغة `pg_dump` المعتادة.
