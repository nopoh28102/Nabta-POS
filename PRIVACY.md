# Privacy notice / بيان الخصوصية

Nabta POS is designed as a local point-of-sale application. Its Electron desktop app communicates with a locally embedded server at 127.0.0.1 for everyday operations, and stores operational data and backups locally. The application offers local export and backup features.

**Updates:** on application start, a packaged version checks the public GitHub Releases update feed. If a new version is available, the user chooses whether to download it and when to install it. Network requests to GitHub reveal ordinary connection details (such as IP address) to GitHub according to GitHub's privacy terms. The app does not need a user GitHub access token for updates.

**Hardware and local network:** optional scanner/printing functions and local-network services may communicate with connected devices. Backups and exports are managed on the user's system.

**Other integrations:** before promoting this notice as a comprehensive privacy policy, maintainers must review bundled dependencies, optional network integrations, device drivers, and user-facing configuration screens. This document does not claim that no network connection can ever occur.

Contact the maintainers through the [GitHub repository](https://github.com/nopoh28102/Nabta-POS/issues) for privacy questions. If you choose third-party services, their individual privacy terms may apply.
