# تشغيل الخادم يدويًا بالنقر

يوجد ملف `Nabta-Server-Admin.vbs` بجانب مثبت نبتة داخل مجلد `release`. انقر عليه مرتين ثم وافق على رسالة Windows للمسؤول. سيبدأ الخادم المضمن في الخلفية دون فتح نافذة أوامر، وبعدها افتح نبتة. يوجد `Nabta-Server-Admin.cmd` كبديل إذا كانت سياسات Windows تمنع تشغيل VBS.

يستخدم هذا الملف كحل احتياطي فقط عند تعطل التشغيل التلقائي؛ لا يفتح قاعدة البيانات ولا ينشئ قاعدة جديدة.
