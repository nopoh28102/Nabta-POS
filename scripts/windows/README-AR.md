# تشغيل خادم نبتة تلقائياً على Windows

في الإصدار المثبت لا يحتاج صاحب المتجر إلى تنفيذ الأوامر التالية: مثبت NSIS يعمل بصلاحية المسؤول، وينشئ مهمة Windows باسم `NabtaPOSServer` لتشغيل الخادم عند تسجيل الدخول، وينشئ الشهادة وقواعد الشبكة ويطبق migrations تلقائياً. استخدم [دليل المثبت](../../docs/INSTALLER-AR.md) للتثبيت العادي.

القسم التالي مخصص للتطوير أو التثبيت اليدوي المتقدم فقط:

1. ابنِ المشروع (pnpm build) وأنشئ .env من .env.example.
2. شغّل PowerShell كمسؤول من مجلد المشروع:

~~~powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\windows\install-nabta-server.ps1
~~~

3. اجعل HOST عنوان LAN آمنًا، واستخدم HTTPS بشهادة محلية موثوقة عند ربط جهاز ثانٍ. لا تفتح منفذ PostgreSQL للشبكة؛ الكاشيرات تتصل بمنفذ API فقط.
4. امنح حساب الخدمة صلاحية القراءة والكتابة لمساري DATABASE_DIR وBACKUP_DIR. يفضّل تشغيلها بحساب Windows مخصص محدود الصلاحيات بدل LocalSystem في بيئة المتجر.
5. اربط الجهاز الثاني بعنوان الخادم وشهادة TLS من شاشة إعداد الاتصال، ثم سجّل دخوله بحساب منفصل.

لإزالة الخدمة دون حذف البيانات:

~~~powershell
.\scripts\windows\uninstall-nabta-server.ps1
~~~

الطابعات الحرارية، الميزان، وجهاز الدفع البنكي تحتاج إعداد الجهاز الفعلي وسياسة المتجر؛ مثبت نبتة يضيف قواعد Firewall ضيقة لمنفذي API والاكتشاف داخل شبكات Domain/Private فقط.
