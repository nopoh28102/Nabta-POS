# ربط كاشيرات نبتة عبر Cloudflare

هذا Worker مخصص لتطبيقات نبتة الداخلية فقط، وليس لتطبيق العملاء. يمرر واجهة `/v1/*` إلى الجهاز الرئيسي بعد التحقق من مفتاح أجهزة نبتة. لا تنشر المفتاح في Git أو في متصفح.

1. من مجلد `cloudflare/pos-terminal-relay` نفّذ `npx wrangler deploy`، ثم اربط Worker باسم مثل `pos.nabta.de5.net` من لوحة Cloudflare.
2. أضف السر `NABTA_TERMINAL_ORIGIN` بالقيمة `https://origin.nabta.de5.net`.
3. أنشئ قيمة عشوائية بطول 32 حرفًا أو أكثر، وأضفها باسم `NABTA_TERMINAL_RELAY_KEY`.
4. في نبتة على الجهاز الرئيسي: الإعدادات ← Cloudflare ← ضع رابط `https://pos.nabta.de5.net` ونفس مفتاح أجهزة نبتة، ثم عيّن الجهاز الرئيسي بالرمز `281020`.
5. على كل جهاز كاشير: اختر «ربط جهاز كاشير بالجهاز الرئيسي»، وأدخل الرابط والمفتاح والرمز `281020` واسم نقطة البيع. ينشئ نبتة معرف كاشير مستقل، لكن المخزن والبيانات يبقيان في قاعدة بيانات الجهاز الرئيسي.

لا تثبّت أو تشغّل Tunnel على الأجهزة الثانوية. إذا توقف الجهاز الرئيسي أو الإنترنت، يمنع النظام بيعًا نهائيًا حتى يعود الاتصال؛ وهذا يمنع اختلاف المخزون بين الأجهزة.
