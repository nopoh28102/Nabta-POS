# نبتة دكاني

تطبيق Android مستقل بواجهة HTML عربية محلية مستلهمة من تدفق تطبيق دكاني، لكنه لا يستخدم شعاره أو مفاتيحه أو خدمته. الواجهة تتصل فقط بجسر Android محلي، والجسر هو الذي يستدعي بوابة نبتة المحمية عبر Cloudflare.

## الوظائف المنفذة

- تسجيل دخول نبتة المشفّر على الهاتف.
- بحث وقراءة الباركود بالكاميرا.
- إنشاء صنف جديد وتوليد باركود تلقائي من نبتة عند تركه فارغًا.
- فاتورة استلام مورد: قطعة أو كرتونة، سعر شراء وبيع وصلاحية اختيارية.
- اعتماد الفاتورة بمعاملة واحدة مع طلب طباعة واحد لجهاز نبتة الرئيسي.
- تسجيل صلاحية صنف من دون تغيير رصيده.

لا تحمل واجهة HTML رمز جلسة المستخدم أو مفتاح Cloudflare، ولا يسمح WebView بتصفح صفحات خارج ملف الواجهة المحلي.

## تحديث 1.3.0

- صفحة الديون تدعم البحث، إنشاء عميل بمديونية افتتاحية، والسداد الجزئي للرصيد السابق.
- صفحة التقارير تعرض التقرير الشامل وتُصدر ملف Excel متوافقًا (`.xls`) من الهاتف.
- نتائج البيع ترتب الأصناف المتاحة أولًا، مع بيان واضح للمتاح وغير المتاح.
- الواجهة خضراء متجاوبة وتستخدم رموز Emoji واضحة وتمنع تحديد نصوص الشاشة أثناء التشغيل.
